# waterius.github.io

Статические страницы Ватериуса на GitHub Pages.

| Адрес | Что это |
|---|---|
| [/update/](https://waterius.github.io/update/) | Универсальный заливщик прошивок ESP из браузера |

Сайт отдаётся с корня репозитория (ветка `master`, папка `/`). Сборки нет:
файлы лежат как есть, `.nojekyll` отключает обработку Jekyll.

## /update/

Заливщик на [esptool-js](https://github.com/espressif/esptool-js) от Espressif
(Apache 2.0). Работает целиком в браузере: файл читает сам браузер и отдаёт его
плате по Web Serial — на сервер ничего не загружается, серверной части здесь
нет вообще. Поддерживаются все чипы, которые умеет библиотека: ESP8266 и вся
линейка ESP32.

Прошивка не своя и не зашита в страницу — `.bin` приносит пользователь. Адрес
по умолчанию `0x0` (склеенные с нуля образы), но можно добавить части и указать
каждой своё смещение — как `esptool.py write_flash` с несколькими файлами.

- `update/index.html` — разметка, логотип инлайном
- `update/flasher.css` — стили, токены перенесены из дизайн-системы личного кабинета
- `update/flasher.js` — логика
- `update/img/` — иконка GitHub из тех же ассетов, что на сайте

Версия `esptool-js` в импорте **пинуется намеренно**: безверсионный
`bundle.js` с unpkg подтянет следующий мажор прямо в продакшен, а он уже ломал
формат данных (в 0.6.0 `fileArray[].data` переехал с бинарной строки на
`Uint8Array`, в 0.7.0 на строку бросается исключение).

Проверять локально:

```sh
python3 -m http.server 8000
# http://localhost:8000/update/ — localhost считается защищённым контекстом,
# Web Serial работает без https. Через file:// не проверять: там его нет.
```
